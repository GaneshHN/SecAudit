## 2. Modified & Created Files

The following files were modified or created exclusively to implement health probes and validation testing:

* `server.js` (Modified): Added `/health/liveness` and `/health/readiness` endpoints to the Express API server. Integrated with `HealthCheckService` and global graceful shutdown state (`isShuttingDown`).
* `worker.js` (Modified): Added an isolated Node.js `http` server on `WORKER_HEALTH_PORT` (default 9090) to serve liveness and readiness for the worker daemon. Integrated with `queueProvider.getStats()` and `isShuttingDown`. Added the probe server to the graceful shutdown cleanup sequence.
* `test_health_probes.js` (Created): An automated, deterministic testing script that fully validates liveness, readiness, backpressure triggers, unavailable infrastructure handling, and immediate readiness 503 during a graceful shutdown event.
* `src/events/EventPersister.js` (Fixed bug): Modified to explicitly drop `EntityCreated` events generated by the `EventRepository` to prevent exponential event loops in the in-memory event bus when multiple persisters are running in the same process.

## 3. Implementation Verification

* **Liveness Independence**: Both API and worker liveness endpoints return `200 OK` regardless of queue depth or Docker availability, indicating the process is alive.
* **Readiness under Backpressure**: Worker readiness correctly queries `queueProvider.getStats()` and returns `503 Not Ready` when queued jobs exceed the configurable `READINESS_QUEUE_THRESHOLD`.
* **Readiness under Shutdown**: Both API and Worker readiness probes return `503` immediately when `SIGINT`/`SIGTERM` is received, properly signaling load balancers to route traffic away before the shutdown completes.
* **Information Security**: No sensitive paths, stack traces, credentials, or findings are leaked by the health endpoints.
* **Regression Suite Validation**: The full suite of 17 tests (including `test_health_probes.js`, `test_graceful_shutdown.js`, `test_sandbox_observability.js`, `test_phase4_e2e.js`, etc.) ran and passed successfully with zero failures.
